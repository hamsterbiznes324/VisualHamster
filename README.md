# VisualHamster - Minecraft Client Mod

Мод для улучшения визуального опыта в Minecraft.

## Возможности

- 🔥 **Low Fire** - уменьшение высоты огня на экране
- 💡 **Fullbright** - полная яркость без факелов
- 📊 **Custom HUD** - кастомный интерфейс с:
  - Отображением здоровья
  - Показом брони
  - Координатами
  - Счетчиком FPS
- 👁️ **Hitboxes** - отображение хитбоксов
- ⚙️ **Настройки** - полностью настраиваемые параметры

## Установка

1. Установите Fabric Loader для вашей версии Minecraft (1.21.1)
2. Скопируйте `.jar` файл в папку `mods`
3. Запустите игру

## Сборка

```bash
./gradlew build
```

Готовый мод будет в `build/libs/`

## Горячие клавиши

- `V` - открыть меню настроек (можно изменить в настройках)

## Требования

- Minecraft 1.21.1
- Fabric Loader 0.16.9+
- Fabric API 0.100.0+
